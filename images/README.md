# Folder gambar
Foto prototipe saat ini dipanggil dari URL Unsplash dan belum disimpan secara lokal.
Untuk pengumpulan akhir, dokumentasikan halaman sumber, periksa lisensi tiap aset, dan bila memungkinkan simpan salinan yang penggunaannya diizinkan ke folder ini. Setelah menyimpan file, ubah `src` pada HTML menjadi path lokal seperti `images/nama-file.jpg`.
Semua gambar dekoratif/konten pada HTML telah diberi atribut `alt` yang menjelaskan isi gambar.
