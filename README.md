# Ruang Iklim — Website Edukasi SDG 13 (10 Halaman)

Website edukasi statis bertema perubahan iklim dan lingkungan untuk proyek UTS Pemrograman Web.

## Tujuan
Membantu pembaca memahami perubahan iklim, penyebab, dampak, jejak karbon, mitigasi, adaptasi, dan aksi iklim. Topik ini selaras dengan SDG 13: Penanganan Perubahan Iklim.

## Daftar 10 halaman
1. `index.html` — **Beranda**: pengantar website dan jalur belajar.
2. `edukasi.html` — **Edukasi**: dasar perubahan iklim, efek rumah kaca, dan bukti ilmiah.
3. `penyebab.html` — **Penyebab**: sumber gas rumah kaca dan aktivitas manusia.
4. `dampak.html` — **Dampak**: dampak pada cuaca ekstrem, pangan, air, pesisir, ekosistem, dan masyarakat.
5. `jejak-karbon.html` — **Jejak Karbon**: pengenalan jejak karbon dan cara menilainya secara hati-hati.
6. `mitigasi.html` — **Mitigasi**: upaya mengurangi emisi gas rumah kaca.
7. `adaptasi.html` — **Adaptasi**: upaya mengurangi risiko dari dampak perubahan iklim.
8. `aksi-iklim.html` — **Aksi Iklim**: aksi dari rumah, sekolah/kampus, komunitas, dan rencana 30 hari.
9. `artikel.html` — **Artikel**: bacaan edukasi ringkas.
10. `tentang.html` — **Tentang**: profil proyek, teknologi, anggota tim, dan referensi.

## Teknologi
- HTML5 semantik (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- CSS3 eksternal di `css/style.css`.
- CSS Grid, Flexbox, dan media queries untuk tampilan responsif.
- JavaScript sederhana untuk membuka/menutup menu pada layar kecil.
- Tidak menggunakan framework CSS, backend, database, autentikasi, atau template website.

## Cara menjalankan
Buka `index.html` melalui browser. Foto prototipe memakai URL Unsplash, jadi koneksi internet dibutuhkan untuk menampilkan gambar jarak jauh. Halaman dan CSS merupakan file statis lokal.

## Pengujian yang disarankan
Uji semua halaman pada viewport:
- Desktop: 1440 px
- Tablet: 768 px
- Ponsel: 375 px

Periksa menu navigasi, keterbacaan teks, gambar, jarak antarkomponen, tautan, dan pastikan tidak ada scroll horizontal. Menu di layar kecil dapat dibuka melalui tombol Menu.
