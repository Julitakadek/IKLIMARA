Tentang proyek

Website edukasi untuk belajar dan bergerak

Ruang Iklim dibuat sebagai website edukasi statis bertema SDG 13: Penanganan Perubahan Iklim, dengan fokus pada pengetahuan dasar, dampak, dan langkah nyata.

Tujuan website

Website ini membantu pelajar dan masyarakat umum memahami perubahan iklim melalui informasi yang tersusun, bahasa yang mudah diikuti, dan contoh tindakan di tingkat individu maupun komunitas.

Siapa penggunanya?

Pelajar, mahasiswa, pendidik, dan pembaca umum yang ingin mendapatkan pengantar tentang perubahan iklim dan menemukan sumber lanjutan.

Batasan proyek

Website ini tidak memiliki backend, database, akun pengguna, prakiraan cuaca langsung, atau kalkulator jejak karbon. Konten disediakan sebagai halaman HTML statis dan dapat dikembangkan oleh tim.

Teknologi

Dibangun dengan fondasi web

  • HTML5 untuk struktur dan semantik konten.
  • CSS3 eksternal untuk layout, warna, tipografi, dan responsivitas.
  • CSS Grid dan Flexbox untuk tata letak.
  • Media queries untuk layar desktop, tablet, dan ponsel.
  • JavaScript sederhana hanya untuk menu navigasi seluler.
  • Navigasi konsisten dan tautan antarhalaman.
